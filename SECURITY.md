# Security and privacy

This repository is intentionally static. It has no forms, analytics trackers, cookies, authentication, backend service or external data connection.

## Public-content boundary

- No phone number, residential address or public email.
- No corporate data, customer data, VIN/chassis records, internal URLs, server names or network paths.
- No internal screenshots, spreadsheets, PDFs, PBIX, MSAPP, source workbooks or copied private-repository content.
- No credentials, tokens, cookies or `.env` files.
- Case-study graphics and data are conceptual or synthetic.

Report accidental sensitive-data exposure privately through GitHub's security-advisory flow. Do not include sensitive material in a public issue.
